Server Placement Lab

12 services. 4 limited servers. One shared evaluator.

Decision: int[12] host assignments.

Minimize sum(service latency × host latency) / sum(service latency) in ms.

CPU, RAM, storage and at least two services on every host are mandatory.

0:45–1:30 / search space and reference

16,777,216 assignments; 18,281 feasible

1:30–2:35 / main method

Smart Restart Search

  1. Build a capacity-aware randomized greedy start.
  2. Improve it using moves and swaps.
  3. Restart when its neighborhood has no improvement.
  4. Check the best score after each 10,000-evaluation batch.
  5. Stop after one complete stagnant batch, or at the cap.

Show the Java replay: accepted move, rejected trial and comparison pulse.
